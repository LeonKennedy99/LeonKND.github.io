O **ItemzFlow** não é apenas um gerenciador de jogos; ele possui um sistema integrado para baixar e aplicar patches de performance (como desbloqueio de 60 FPS) e modificações visuais sem a necessidade de editar arquivos manualmente via FTP.

### Requisitos
* PS4 com GoldHEN ativo.
* App **ItemzFlow** v1.08 ou superior instalado.
* Conexão com a internet no PS4 (apenas para baixar a lista de patches; use DNS seguro como o do Al-Azif para evitar atualizações da Sony).

### Passo a Passo
1. **Acesso ao Menu:** Inicie o ItemzFlow e navegue até o jogo que você deseja modificar.
2. **Menu de Opções:** Pressione o botão **Options** (ou o botão configurado para o menu do jogo) e selecione 'Game Patches'.
3. **Download de Patches:** Se for a primeira vez, o app perguntará se deseja baixar a base de dados de patches mais recente. Confirme.
4. **Seleção de Melhorias:**
   * Uma lista de patches disponíveis para o seu CUSA específico aparecerá.
   * Opções comuns incluem: 'Disable Motion Blur', 'Unlock Framerate (60 FPS)', 'Hidden Graphics Settings'.
   * Ative as opções desejadas marcando-as com 'X'.
5. **Aplicação:** Após selecionar, os patches serão aplicados na memória assim que o jogo for iniciado através do próprio ItemzFlow.
6. **Mods Externos:** Para mods maiores (como o Bully HD Mod), coloque os arquivos na pasta `/data/ItemzFlow/mods/[CUSA-DO-JOGO]/` e ative a opção 'Enable Mods' no menu do jogo no ItemzFlow.

### Avisos de Risco
* Patches de 60 FPS podem causar superaquecimento em modelos PS4 Fat ou Slim se o jogo for muito pesado. Monitore a temperatura.
* Alguns patches de 60 FPS podem causar bugs na física do jogo (ex: jogos da Bethesda ou FromSoftware).

### Solução de Problemas
* **Patch não aparece:** Verifique se o código CUSA do seu jogo e a versão instalada (update) são compatíveis com o patch listado. Muitos patches exigem que o jogo esteja na versão 1.00 ou em um update específico.
* **O jogo trava no início:** Desative todos os patches e reative um por um para identificar qual está causando o conflito.
