A ferramenta **PPPwn_cpp**, desenvolvida por xfangfang, foi atualizada para a versão 1.2.0. Diferente da versão original em Python, esta implementação escrita em C++ é ideal para dispositivos com pouco poder de processamento, como roteadores e computadores antigos, oferecendo uma execução muito mais veloz.

A v1.2.0 traz melhorias na detecção de pacotes PADI e uma lógica de retry mais robusta, o que aumenta significativamente a taxa de sucesso da primeira tentativa do Jailbreak, especialmente no Firmware 11.00. Também foram adicionados novos parâmetros de configuração via linha de comando para usuários avançados.

**Firmwares Suportados:** 9.00, 9.60, 10.00, 10.01 e 11.00.

**Como usar:**
Execute o binário via terminal/prompt de comando apontando para a interface de rede conectada ao PS4 via cabo Ethernet, utilizando o comando correspondente ao seu firmware.
