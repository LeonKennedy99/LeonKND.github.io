A equipe GoldHEN disponibilizou o **Cheat Manager v1.2.7**, trazendo uma atualização massiva no banco de dados de trapaças (cheats) e patches de performance. A principal novidade é a inclusão de suporte para títulos recentemente portados ou atualizados no console, além de correções no sistema de atualização online do app.

Para utilizar, é necessário ter o GoldHEN ativo no sistema. O aplicativo permite baixar os códigos diretamente pela internet no console e ativá-los em tempo real através do menu flutuante. Esta versão também corrige um erro que causava o fechamento inesperado ao carregar cheats de jogos com múltiplos arquivos CUSA.
