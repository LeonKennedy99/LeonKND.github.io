A equipe do GoldHEN disponibilizou o **GoldHEN Cheat Manager v1.2.6**. Este utilitário é essencial para quem utiliza o plugin de cheats integrado ao GoldHEN, permitindo baixar as bases de dados mais recentes sem a necessidade de um PC.

Destaques da versão 1.2.6:
- Adição de centenas de novos códigos para lançamentos recentes e atualizações de jogos.
- Nova opção de 'Favoritos' para acessar rapidamente cheats de jogos que você joga com frequência.
- Correção na detecção de CUSA para versões de jogos de diferentes regiões.

Para usar, você deve ter o GoldHEN ativo. Abra o aplicativo, conecte o console à internet e selecione 'Update' para baixar a lista de cheats mais recente. Depois, basta entrar no jogo e segurar o botão 'Share' (ou o atalho configurado) para ativar o menu de trapaças.
