O **PS4 App Lock**, desenvolvido pelo renomado Lapy, é uma ferramenta essencial para quem compartilha o console com outras pessoas ou deseja restringir o acesso a conteúdos específicos (como jogos violentos para crianças). Ele permite que você defina uma senha numérica (PIN) para qualquer aplicativo ou jogo instalado.

### Requisitos

*   PS4 com qualquer firmware compatível com desbloqueio (5.05 até 11.00+).
*   GoldHEN ou outro ambiente de homebrew ativo.
*   Aplicativo **PS4 App Lock v1.07**.

### Passo a Passo

1.  **Instalação:** Baixe o PKG do PS4 App Lock e instale-o via *Package Installer*.
2.  **Configuração Inicial:** Ao abrir o aplicativo pela primeira vez, ele solicitará que você selecione a versão do seu firmware para garantir a compatibilidade.
3.  **Definição do PIN:** O app pedirá para você criar uma senha numérica (PIN). Você pode usar até 12 dígitos. Escolha uma senha fácil de lembrar, mas difícil de adivinhar.
4.  **Bloqueio de Aplicativos:** 
    *   O aplicativo exibirá uma lista com todos os jogos e apps instalados no seu PS4.
    *   Navegue pela lista e pressione **X** sobre os itens que deseja bloquear. Um ícone de cadeado aparecerá sobre a miniatura do jogo.
    *   Para bloquear ou desbloquear todos de uma vez, use os botões **L1/R1** conforme indicado na interface.
5.  **Ativação:** Após selecionar os apps, feche o PS4 App Lock. Agora, sempre que alguém tentar iniciar um dos jogos marcados, o sistema solicitará o PIN antes de permitir a execução.

### Avisos de Risco

*   **Atenção:** Se você esquecer o seu PIN, o acesso aos jogos bloqueados será perdido. Caso isso aconteça, você precisará acessar o sistema de arquivos via FTP ou PS4-Xplorer e deletar os dados salvos (*save data*) do aplicativo PS4 App Lock para resetar as configurações.
*   O bloqueio é removido se o console for reiniciado e o desbloqueio (HEN) não for reativado, pois o app depende do ambiente homebrew para funcionar.

### Solução de Problemas

*   **Ícone de cadeado não aparece:** Certifique-se de que o GoldHEN está ativo e que você pressionou **X** para confirmar a seleção antes de sair do aplicativo.
