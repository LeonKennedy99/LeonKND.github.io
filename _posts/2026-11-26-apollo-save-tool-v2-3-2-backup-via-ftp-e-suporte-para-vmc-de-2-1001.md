Bucanero lançou o **Apollo Save Tool v2.3.2**, trazendo funcionalidades que facilitam muito a vida de quem não quer perder seu progresso. A grande novidade é a integração com servidores FTP, permitindo que você faça backup e restaure seus saves diretamente para a rede ou nuvem sem precisar de cabos.

### Novidades da versão v2.3.2:
- **Servidor FTP Integrado:** Faça upload de saves zipados para servidores definidos pelo usuário.
- **Gerenciamento de VMC de PS2:** Suporte completo para imagens de Virtual Memory Card (.PS2, .VM2, .VMC).
- **Scripts Python:** Agora é possível rodar scripts customizados em Python para edição avançada de saves.
- **Checksums e Cheats:** Adicionados novos códigos para jogos como *Resident Evil 7*, *Lunar 1 & 2 Remastered* e *Like a Dragon: Pirate Yakuza in Hawaii*.

### Compatibilidade:
Funciona em todos os firmwares com suporte a HEN/GoldHEN (desde o 5.05 até versões recentes como 11.00+).
