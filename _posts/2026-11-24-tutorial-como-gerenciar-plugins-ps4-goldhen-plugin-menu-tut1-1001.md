### O que é o GoldHEN Plugin Menu?
O Plugin Menu é uma funcionalidade integrada nas versões recentes do GoldHEN (v2.4b ou superior) que permite ao usuário carregar, ativar e desativar arquivos no formato `.prx`. Esses plugins podem adicionar diversas funcionalidades ao sistema, como contadores de quadros por segundo (FPS), sobreposições de temperatura e patches de desempenho (como o libhijacker para 60 FPS).

### Requisitos
* Console PS4 com exploit (Jailbreak) ativo.
* GoldHEN versão 2.4b ou superior instalado e em execução.
* Acesso à internet ou USB para colocar os arquivos de plugin na pasta correta (opcional, se já não estiverem inclusos).

### Passo a Passo
1. **Acessar as Configurações:** No menu principal do seu PS4, navegue até o ícone de 'Configurações'.
2. **Menu GoldHEN:** Logo no topo da lista, selecione a opção 'GoldHEN'.
3. **Seção de Plugins:** Role para baixo até encontrar a opção 'Plugin Settings' ou 'Plugin Menu'.
4. **Configurar Plugins:** Selecione 'Enable Plugin Loader' para garantir que o sistema possa ler os arquivos.
5. **Gerenciar Lista:** Entre em 'Plugin Manager' (se disponível na sua versão) ou acesse a lista de plugins carregados. Aqui você verá plugins como `afk-disabler`, `framecounter` ou plugins de trapaça.
6. **Ativar/Desativar:** Use o botão de confirmação para marcar os plugins que deseja que iniciem com o sistema ou com os jogos.
7. **Reinicialização:** Alguns plugins exigem que o jogo seja reiniciado para entrarem em vigor.

### Avisos de Risco
* O uso excessivo de plugins simultâneos pode causar instabilidade no sistema ou fechamento inesperado de jogos (Crush/CE-34878-0).
* Plugins mal configurados podem interferir na performance do console.

### Solução de Problemas
* **Plugins não aparecem:** Certifique-se de que os arquivos `.prx` e o arquivo de configuração `plugins.ini` estão localizados corretamente no diretório `/data/GoldHEN/plugins/` via FTP ou gerenciador de arquivos.
* **Console trava ao carregar:** Se o console travar após ativar um plugin, reinicie o PS4, reative o GoldHEN mantendo o botão L1 pressionado para desativar o carregamento automático de plugins e remova o item problemático.
