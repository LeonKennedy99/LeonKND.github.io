O PS4 Payload Guest foi atualizado para a versão 1.02, trazendo maior compatibilidade com os payloads mais recentes da cena, incluindo versões experimentais de kernels de Linux e ferramentas de dump de memória. Este app é essencial para quem não quer depender de um computador ou smartphone toda vez que precisa enviar um payload específico para o console.

A ferramenta funciona escaneando a raiz de um dispositivo USB em busca de arquivos no formato '.bin'. Ao abrir o aplicativo no PS4, uma lista de payloads disponíveis no pendrive é exibida, bastando selecionar o desejado para a execução imediata. A versão 1.02 melhora o suporte para o firmware 11.00 e corrige problemas de exibição em resoluções 4K no PS4 Pro.
