O PS4-Waker é uma ferramenta poderosa que permite acordar o console do Rest Mode e enviar comandos via linha de comando ou web. A versão 1.4.0 traz correções para o protocolo de descoberta em redes que utilizam firmwares 9.00 e 11.00.

### Funcionalidades:
- **Wake-on-LAN:** Ligue o console diretamente pelo seu smartphone ou PC.
- **Injeção de Comandos:** Envie comandos para abrir aplicativos específicos ou simular pressionamentos de botões.
- **Automação:** Ideal para desenvolvedores que desejam automatizar testes de homebrew no console sem intervenção manual constante.

Para funcionar, o console deve estar configurado para permitir a ativação via rede nas configurações de economia de energia.
