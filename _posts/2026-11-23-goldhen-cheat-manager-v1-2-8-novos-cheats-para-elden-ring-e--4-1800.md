A nova atualização v1.2.8 do GoldHEN Cheat Manager traz uma base de dados expandida, focada em títulos populares e patches de 60FPS. Além das trapaças tradicionais, como vida infinita e recursos ilimitados, foram adicionados códigos de otimização de performance para jogos como Elden Ring (v1.10) e Red Dead Redemption 2.

O aplicativo permite baixar as trapaças mais recentes diretamente pelo console, desde que ele esteja conectado à internet. A versão 1.2.8 corrige um bug onde alguns códigos não eram aplicados corretamente se o jogo estivesse em uma versão de região diferente (CUSA). Para usar, basta abrir o Cheat Manager, atualizar a base de dados e, dentro do jogo, segurar o botão 'Share' para abrir o menu do GoldHEN e selecionar as trapaças desejadas.
