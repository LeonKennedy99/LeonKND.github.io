A equipe GoldHEN disponibilizou a versão 1.5.0 do Cheat Manager. A principal novidade é a inclusão de um sistema de ordenação e filtros, permitindo que os usuários organizem a lista de cheats por título, ID do jogo ou data de atualização. O motor de busca interna foi reescrito para ser mais responsivo, especialmente em bibliotecas com milhares de entradas. Esta versão também adiciona suporte experimental para o formato JSON estendido, que permite descrições de cheats mais detalhadas. Compatível com todas as versões do GoldHEN, a instalação é feita via PKG. Após abrir o app, recomenda-se usar a função 'Update' para baixar a base de dados de cheats mais recente do repositório oficial.
