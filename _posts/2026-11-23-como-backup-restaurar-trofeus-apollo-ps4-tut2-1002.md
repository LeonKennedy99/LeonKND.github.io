Embora o GoldHEN permita desbloquear troféus, o Apollo Save Tool é a ferramenta essencial para gerenciar, fazer backup e restaurar os dados de conquistas que já estão no seu console, especialmente útil antes de reconstruções de banco de dados ou trocas de HD.

### O que é o Apollo Save Tool?
É uma ferramenta de gerenciamento de dados que permite manipular saves de PS1, PS2 e PS4, além de oferecer um módulo completo para gerenciar os troféus da conta local offline.

### Requisitos
*   PS4 desbloqueado com GoldHEN.
*   Apollo Save Tool instalado (arquivo `.pkg`).
*   Pen drive formatado em exFAT para exportar os arquivos.

### Passo a Passo
1.  **Acesso ao Menu:** Abra o Apollo Save Tool no seu PS4.
2.  **Gestão de Troféus:** No menu principal, navegue até a opção **Trophy Tools**.
3.  **Backup Local:** Selecione **Trophy Management**. Aqui você verá a lista de jogos com troféus vinculados ao seu perfil local.
4.  **Exportação:** Selecione o jogo desejado (ou use a opção de selecionar todos) e escolha **Export Trophy (Zip)** para salvar os dados no armazenamento interno ou **Export to USB** para salvar no pen drive.
5.  **Restauração:** Caso precise restaurar em um novo perfil ou após um erro, volte ao menu *Trophy Tools*, selecione **Import Trophy** e localize os arquivos no seu USB.

### Avisos de Risco
*   **Banimento da PSN:** **NUNCA** tente sincronizar troféus modificados ou restaurados via Apollo com os servidores oficiais da Sony. Isso resultará em banimento imediato da conta e do console.
*   **Uso Offline:** Use esta ferramenta estritamente para contas offline ou perfis de backup.

### Solução de Problemas
*   **Troféus não aparecem:** Após a restauração, pode ser necessário usar a opção 'Rebuild Database' no modo de segurança do PS4 ou através de ferramentas de terceiros para que o sistema reconheça a nova lista.
