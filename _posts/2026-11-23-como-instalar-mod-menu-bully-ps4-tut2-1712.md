Este tutorial ensina como aplicar um Mod Menu na versão de PS4 do jogo Bully: Scholarship Edition (que roda via emulação oficial de PS2). O mod permite alterar o clima, spawnar veículos, trocar roupas e ativar invencibilidade em tempo real.

### Requisitos
* PS4 com GoldHEN (qualquer firmware compatível).
* Jogo Bully (CUSA03507 ou compatível) instalado.
* O arquivo do Mod Menu (geralmente um arquivo de script compilado para o emulador).
* PS4-Xplorer 2.0 instalado no console.

### Passo a Passo
1. **Baixe o Mod:** Obtenha os arquivos do mod menu (geralmente nomeados como `Scripts.img` ou patches específicos).
2. **Transfira para o USB:** Coloque os arquivos do mod em um pendrive formatado em exFAT.
3. **Localize a pasta do jogo:** No PS4, abra o PS4-Xplorer e navegue até `/user/app/LUSAXXXXX` (onde LUSA ou CUSA é o ID do seu jogo Bully).
4. **Backup (Obrigatório):** Antes de substituir qualquer arquivo, copie o arquivo original `Scripts.img` (localizado dentro da pasta de dados do jogo) para uma pasta segura no seu pendrive.
5. **Substitua o arquivo:** Copie o arquivo do Mod Menu do seu pendrive e cole na pasta correspondente no HD do PS4, substituindo o original.
6. **Inicie o jogo:** Abra o Bully normalmente.
7. **Ative o menu:** Geralmente, os mods de Bully são ativados pressionando uma combinação de botões (Ex: L1 + Direcional para cima ou R1 + L1).

### Avisos de Risco
* Modificar arquivos do sistema de arquivos do jogo pode corromper o seu save game. Sempre faça backup antes.
* Se o jogo travar na tela de carregamento, o mod pode ser incompatível com a versão/região do seu jogo.

### Solução de Problemas
* **O menu não aparece:** Verifique se o ID da região do mod é o mesmo do seu jogo (ex: o mod para a versão americana pode não funcionar na europeia).
* **Tela preta:** Remova o mod e restaure o backup do arquivo `Scripts.img` original.
