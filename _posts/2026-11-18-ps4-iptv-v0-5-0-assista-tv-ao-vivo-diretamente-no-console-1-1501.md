O desenvolvedor **realityofai32-stack** lançou o **PS4 IPTV v0.5.0**, uma ferramenta dedicada para usuários que desejam assistir a canais de TV via streaming diretamente pelo PlayStation 4. O aplicativo suporta o carregamento de listas no formato M3U e oferece uma interface otimizada para o uso com o DualShock 4.

Nesta versão inicial estável, o foco foi a compatibilidade com o firmware 11.00 e a estabilidade do buffer de vídeo. O app permite organizar categorias e carregar logos de canais se estiverem presentes na lista. Para instalar, basta utilizar o Package Installer do GoldHEN no seu console desbloqueado.
