O desenvolvedor Lapy atualizou o **PS4-Xplorer 2.0** para a versão **2.18**. A grande novidade é a implementação do suporte experimental para extração de arquivos compactados no formato **.RAR5**, algo que antes causava erros ou não era reconhecido pelo sistema. Além disso, foram feitas pequenas correções na interface de usuário (UI) para evitar que o texto ficasse cortado em resoluções 4K no PS4 Pro.

Este homebrew é essencial para quem precisa mover arquivos entre o HDD interno e dispositivos USB, editar arquivos `.ini` ou gerenciar pastas de mods. A instalação é feita via PKG e o aplicativo é compatível com todos os consoles que possuem suporte a homebrew.
