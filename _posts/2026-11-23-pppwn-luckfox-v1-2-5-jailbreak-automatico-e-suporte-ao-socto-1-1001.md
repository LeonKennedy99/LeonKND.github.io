A atualização v1.2.5 do **PPPwn-Luckfox** traz melhorias significativas para quem utiliza o microcontrolador Luckfox Pico (Pro/Max/Plus) para automatizar o exploit do PS4. A principal novidade é a compatibilidade com o **SocToolKit**, que permite flashar a imagem diretamente via USB, eliminando a necessidade de ferramentas de rede como o Mobaxterm ou acesso via SSH para a configuração inicial.

Além disso, esta versão introduz a **detecção automática do GoldHEN**, evitando que o exploit seja recarregado desnecessariamente após o console despertar do Modo de Repouso. O desenvolvedor também incluiu imagens pré-instaladas para facilitar o processo ('hassle-free'), onde o usuário só precisa escolher o arquivo correspondente ao seu firmware (suporte de 9.00 a 11.00) e modelo de Luckfox. Caso utilize a versão com Web UI, o endereço IP padrão foi alterado para `10.1.1.1`.
