O **PS4 PKG Tool** foi atualizado para a versão 1.8.0, trazendo melhorias de performance e novas funções de extração de dados. Esta ferramenta para Windows permite visualizar informações detalhadas de arquivos PKG sem precisar instalá-los.

Recursos novos e aprimorados:
- Suporte para extrair ícones e artes de fundo (PIC1) em alta resolução.
- Função de verificação de integridade (Hash check) para garantir que o PKG não está corrompido.
- Interface atualizada com suporte para temas escuros e melhor organização de colunas.

Como usar:
1. Baixe e execute o programa no Windows.
2. Aponte para a pasta onde seus arquivos PKG estão armazenados.
3. O programa listará automaticamente o título, ID do jogo (CUSA), versão do firmware mínima exigida e se é um jogo base, patch ou DLC.
