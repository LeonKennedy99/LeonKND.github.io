A equipe GoldHEN lançou a versão v2.4b18.15, uma atualização incremental que visa resolver problemas de estabilidade relatados pela comunidade nas versões anteriores. O foco principal deste lançamento é o sistema de carregamento de plugins (Plugin Loader), que apresentava falhas intermitentes ao iniciar o sistema em determinados modelos de PS4 Pro.

### Novidades desta versão:
- **Correção de Crashes:** Resolvido um problema onde o console desligava inesperadamente ao carregar múltiplos plugins simultaneamente.
- **Melhoria no Klog:** O log do kernel agora é mais preciso, ajudando desenvolvedores a depurar falhas em homebrews.
- **Estabilidade do Servidor FTP:** O servidor integrado recebeu melhorias de performance para transferência de arquivos grandes.

### Firmware Compatível:
Compatível com firmwares de 5.05 até 11.00 (e suporte experimental para 14.02 via offsets atualizados).

### Como Instalar:
Para utilizar, basta injetar o payload via seu host de preferência ou atualizar o arquivo `goldhen.bin` na raiz do seu dispositivo USB caso utilize o método de boot automático.
