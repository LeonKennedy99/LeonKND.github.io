O **Apollo Save Tool** é uma ferramenta indispensável para gerenciar saves. Um dos seus recursos mais úteis é o 'Region Change', que permite que um save da região americana (US) funcione em um jogo da região europeia (EU) ou brasileira (BR), por exemplo.

### Requisitos
* PS4 com Jailbreak ativo (GoldHEN ou similar).
* App **Apollo Save Tool** instalado.
* O arquivo de save que você deseja converter (pode estar no console ou em um USB).

### Passo a Passo
1. **Identificação:** Abra o Apollo Save Tool no seu PS4. Vá em 'User Saves' para ver os saves presentes no seu console.
2. **Backup:** Selecione o save que deseja converter e escolha a opção 'Export to USB' para ter uma cópia de segurança.
3. **Mudança de Região:**
   * Com o save selecionado no menu do Apollo, procure a opção 'Change Region'.
   * O aplicativo listará os códigos de ID de produto (CUSA) compatíveis detectados no seu console ou banco de dados.
   * Selecione o CUSA correspondente à versão do jogo que você instalou.
4. **Resign (Reassinatura):**
   * Após mudar a região, selecione a opção 'Apply Changes' ou 'Resign'. Isso vinculará o save à sua conta de usuário atual (User ID).
5. **Conclusão:** Saia do aplicativo e inicie o jogo. O save agora deve ser reconhecido normalmente pela nova versão do título.

### Avisos de Risco
* Nem todos os jogos permitem a conversão de região de forma perfeita. Alguns jogos possuem estruturas de save diferentes entre regiões (raro, mas acontece), o que pode causar corrupção.
* Sempre faça backup do save original antes de aplicar qualquer patch.

### Solução de Problemas
* **Save corrompido ao carregar:** Tente usar a opção 'Fake Save Data Owner' nas configurações do GoldHEN se o Apollo não conseguir assinar corretamente o arquivo.
* **CUSA não encontrado:** Você precisará digitar manualmente o código CUSA da nova região se o Apollo não o detectar automaticamente.
