Desenvolvido para usuários que se preocupam com o superaquecimento, o **PS4 Temperature Monitor v1.0.1** é uma ferramenta simples que exibe as leituras térmicas dos sensores internos do PlayStation 4. Ao contrário de payloads complexos, este homebrew foca apenas na exibição clara dos dados em Celsius ou Fahrenheit.

A ferramenta é útil para testar a eficácia de novas pastas térmicas ou ajustes na velocidade da ventoinha feitos via Orbis Toolbox. Esta atualização v1.0.1 corrige um bug onde a interface não atualizava os valores após o console sair do modo de repouso (Rest Mode).
