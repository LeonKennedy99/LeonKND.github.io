Dando continuidade ao desenvolvimento do exploit PPPwn, a versão 1.8.0 da interface gráfica para Windows traz melhorias significativas na compatibilidade de hardware. Muitos usuários que utilizavam adaptadores USB-Ethernet enfrentavam erros de 'Timeout', que foram mitigados nesta build.

### Mudanças Principais:
- **Nova Engine de Injeção:** Utiliza uma versão otimizada do Npcap para garantir que os pacotes do exploit cheguem ao PS4 sem perda de dados.
- **Interface intuitiva:** Adição de um log colorido para facilitar a identificação de em qual estágio o exploit falhou.
- **Auto-Update de Stage2:** Agora a ferramenta verifica automaticamente se existe uma versão mais nova do binário stage2.

### Requisitos:
- PC com Windows 10/11.
- Cabo Ethernet conectado entre o PC e o PS4.
- PS4 no firmware 11.00 ou inferior.
