O projeto **Mast1c0re**, que utiliza uma vulnerabilidade no emulador oficial de PS2 dentro do PS4, recebeu uma atualização importante no seu carregador de rede. O **PS2 Network Game Loader v1.0.1** agora suporta o envio de arquivos ISO maiores que 4GB e melhora a compatibilidade com roteadores antigos.

### Como utilizar:
- Você precisará de uma cópia legítima do jogo *Okage: Shadow King* instalada no seu PS4.
- Execute o save modificado do Mast1c0re no console.
- No PC, use a ferramenta de envio para carregar a ISO de PS2 desejada via endereço IP.

Este método é uma alternativa excelente para rodar jogos de PS2 sem precisar criar PKGs customizados, funcionando inclusive em firmwares onde o Jailbreak completo ainda não é tão estável.
