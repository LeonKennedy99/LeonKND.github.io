### O que é?
O **PS4 Offline Account Activator** é uma ferramenta para Windows que permite associar um ID de conta (Account ID) a um perfil local do PlayStation 4. Isso é essencial para usuários com jailbreak que desejam usar o Remote Play oficial, copiar saves para o USB ou usar ferramentas de edição de saves, já que essas funções normalmente exigem uma conta vinculada à PlayStation Network (PSN).

### Requisitos
* PlayStation 4 no firmware 5.05 até 11.00 com **GoldHEN** ou outro payload de jailbreak ativo.
* Um PC com Windows conectado na mesma rede que o PS4.
* O software PS4 Offline Account Activator instalado no PC.

### Passo a Passo
1. **Preparação no PS4:** Ligue o console, ative o GoldHEN e certifique-se de que a opção 'Bin Loader' está ativa nas configurações do GoldHEN (ou que o console está aguardando payloads na porta 9020).
2. **Identificação:** No PS4, vá em Configurações > Gerenciamento de Login > Gerenciamento de Usuários e crie um novo usuário local (não tente logar na PSN).
3. **No PC:** Abra o PS4 Offline Account Activator. No campo 'PS4 IP Address', digite o endereço IP do seu console.
4. **Conexão:** Clique em 'Connect'. Se a conexão for bem-sucedida, a lista de usuários locais do console aparecerá na interface.
5. **Ativação:** Selecione o usuário que você deseja ativar. No campo 'Account ID', você pode inserir um ID específico (se estiver recuperando saves antigos) ou clicar em 'Set Random ID'.
6. **Finalização:** Clique no botão 'Activate'. O PS4 pode reiniciar ou apenas atualizar a interface. Verifique nas configurações de usuário se agora existe um ID vinculado.

### Avisos de Risco
* **Nunca** use este procedimento em uma conta que já possui um vínculo real com a PSN, pois isso sobrescreverá os dados de licença locais.
* O uso de IDs aleatórios pode impossibilitar o uso de saves antigos que estavam vinculados a outro ID.

### Solução de Problemas
* **Falha na conexão:** Verifique se o firewall do Windows não está bloqueando o programa e se o PS4 e o PC estão no mesmo roteador.
* **Usuários não aparecem:** Certifique-se de que o GoldHEN está na versão mais recente e que o payload 'Bin Loader' está rodando.
