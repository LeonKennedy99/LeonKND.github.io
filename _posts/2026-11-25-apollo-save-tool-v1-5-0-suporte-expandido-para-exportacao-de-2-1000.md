A **Apollo Save Tool** foi atualizada para a versão **v1.5.0**, consolidando-se como a ferramenta definitiva para manipulação de arquivos de salvamento no PlayStation 4. Além de permitir a ativação de cheats integrados, a nova versão traz melhorias significativas na decodificação de saves de jogos mais recentes.

**Principais mudanças:**
- Suporte para exportar saves em formato bruto (.dat) para uso em emuladores ou editores externos.
- Atualização do banco de dados de cheats online (mais de 100 novos jogos adicionados).
- Melhoria na interface de usuário para exibição de detalhes de troféus.
- Correção de bugs ao montar partições de save em firmwares 11.00.

Para utilizar, execute o app no PS4, selecione o jogo desejado e escolha entre aplicar patches, fazer backup ou re-assinar o save para outra conta (User ID).
