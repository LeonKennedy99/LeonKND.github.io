O desenvolvedor **Nueex** lançou a versão 3.0 do **PS MTP Explorer**, uma ferramenta essencial para quem deseja gerenciar o sistema de arquivos do PlayStation 4 de forma prática. Diferente do FTP, o protocolo MTP (Media Transfer Protocol) permite que você conecte o console diretamente a um PC ou celular via cabo USB e navegue pelas pastas como se fosse um dispositivo de armazenamento comum.

A v3.0 traz melhorias significativas na estabilidade de transferências de arquivos grandes e suporte aprimorado para firmwares recentes, incluindo o 11.00. Com este homebrew, é possível mover logs, capturas de tela e arquivos de configuração rapidamente, eliminando a lentidão comum das redes Wi-Fi ou a necessidade de remover o HDD para manutenções básicas.
