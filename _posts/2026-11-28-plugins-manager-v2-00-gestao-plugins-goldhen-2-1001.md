O Plugins Manager v2.00 é uma ferramenta essencial para quem utiliza o ecossistema GoldHEN no PS4. Esta nova versão permite ativar, desativar e configurar plugins (.prx) sem a necessidade de editar manualmente arquivos de texto via FTP. A interface foi redesenhada para oferecer carregamento mais rápido e suporte para backups automáticos da pasta de plugins antes de qualquer alteração. É compatível com o GoldHEN v2.3 e superior, facilitando o uso de ferramentas como o Virtual Trophy e patches de 60 FPS.
