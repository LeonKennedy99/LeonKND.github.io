O **Apollo Save Tool** recebeu a versão v2.4.0, consolidando-se como a ferramenta definitiva para gerenciamento de dados no PS4. O destaque absoluto desta atualização é o suporte a **scripts em Python**, permitindo que usuários avançados criem e executem scripts diretamente no console para edição e automação de saves, utilizando o novo módulo `apollo` integrado.

Outra adição surpreendente é a capacidade de gerenciar imagens de **Virtual Memory Card (VMU) do Dreamcast**, com suporte para arquivos .BIN, .DCM e .VMU. A atualização também traz novos códigos de trapaça para títulos como *Metaphor: ReFantazio*, *Resident Evil 7: Biohazard* e *Like a Dragon: Pirate Yakuza in Hawaii*. O motor de patches foi atualizado para a versão v3.0.0, corrigindo bugs de ordenação de bytes e melhorando a estabilidade geral.
