A versão v2.11.0 do ps4-remote-pkg-sender (ferramenta baseada em Electron para Windows, Mac e Linux) foi lançada com uma interface de usuário refinada. O destaque é o novo sistema de gerenciamento de fila, que permite pausar e retomar envios sem perder o progresso atual. Foi corrigido um bug que impedia o reconhecimento de consoles em redes Mesh ou com isolamento de AP. Para usar, instale o aplicativo no PC, insira o IP do PS4 (com o Remote PKG Installer aberto no console) e arraste os arquivos PKG para a janela do programa. Esta versão é altamente recomendada para usuários no Firmware 11.00 que utilizam o GoldHEN.
