O **Apollo Save Tool** recebeu uma atualização massiva para a versão **3.0.0**, trazendo melhorias significativas no seu motor de patches e expandindo a compatibilidade com saves de consoles clássicos.

### Novidades da Versão 3.0.0
* **Apollo Patch Engine v3.0.0:** Reescrita do sistema de aplicação de códigos para maior estabilidade.
* **Dreamcast VMU:** Agora é possível gerenciar imagens de Virtual Memory Card (.BIN, .VMI, .VMS, .DCI) diretamente no PS4.
* **MGS Peace Walker:** Suporte para descriptografia de saves de PSP, facilitando a portabilidade.
* **Prefixos de Código:** Novos prefixos `[SW:]`, `[BSD:]`, `[LE:]` e `[BE:]` para maior controle na aplicação de cheats de terceiros.

Instale o PKG e execute o app para que ele detecte automaticamente seu PSID e Account-ID.
