O **Remote Lua Loader**, desenvolvido por **shahrilnet**, é um novo payload focado em simplificar a execução de scripts LUA no PS4. Em vez de empacotar scripts em PKGs ou movê-los via USB, esta ferramenta permite enviá-los diretamente do PC para o console através da rede local.

O loader é compatível com o sistema de payloads do GoldHEN e funciona de forma integrada com o *Payload Guest*. Ele é ideal para testar mods de interface, automações de sistema ou homebrews simples escritos em LUA. Para utilizar, carregue o payload no PS4 e use o script cliente no computador para enviar o arquivo `.lua` desejado.
