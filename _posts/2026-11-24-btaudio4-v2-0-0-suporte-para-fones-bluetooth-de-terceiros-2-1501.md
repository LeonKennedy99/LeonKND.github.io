O **BTAudio4 v2.0.0**, desenvolvido por **alexutzusoft**, é a solução definitiva para a restrição de áudio Bluetooth do PS4. Nativamente, a Sony limita o console a apenas alguns fones oficiais, mas este homebrew permite o pareamento de fones de ouvido, adaptadores e caixas de som Bluetooth genéricas.

Nesta atualização v2.0.0, a latência do áudio foi drasticamente reduzida, tornando o app viável para jogos competitivos. Além disso, a interface de pareamento foi renovada, permitindo gerenciar dispositivos salvos de forma mais intuitiva. Para funcionar, o console deve estar com o **GoldHEN** ativo para permitir o carregamento dos drivers de áudio customizados.
