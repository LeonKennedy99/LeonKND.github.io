### O que é?
O **PS4 Offline Web Activator** é uma ferramenta baseada em navegador que permite atribuir um ID de conta da PlayStation Network (PSN) a um perfil local no PS4 sem precisar conectar o console aos servidores da Sony. Isso é essencial para habilitar funções que exigem uma conta ativada, como o Remote Play e a exportação de saves para dispositivos USB.

### Requisitos
* Console PS4 com GoldHEN ou outro exploit ativo.
* Acesso ao navegador do console ou uso de um host de payloads.
* Seu **Account ID** de 16 dígitos (pode ser obtido em sites como o PSN ID Finder usando seu antigo nome de usuário ou via arquivos de save antigos).

### Passo a Passo
1.  **Prepare o console:** Certifique-se de que o exploit (GoldHEN) está carregado.
2.  **Acesse a ferramenta:** No navegador do PS4, acesse o endereço do host que contém o Web Activator (como o site oficial do sleirsgoevy ou um host local).
3.  **Carregue o Payload:** Clique no botão correspondente ao "Web Activator". O console exibirá uma mensagem indicando que está aguardando a conexão.
4.  **Conecte e Identifique:** A página mostrará uma lista de usuários locais no console. Selecione o usuário que deseja ativar.
5.  **Insira o ID:** Digite o seu **Account ID** de 16 dígitos no campo solicitado. Se você não tiver um, pode inserir um valor hexadecimal aleatório de 16 caracteres, mas lembre-se que saves antigos não serão compatíveis.
6.  **Ative:** Clique em "Set ID & Activate". O console deverá reiniciar ou confirmar a ativação.
7.  **Verifique:** Vá em Configurações > Gerenciamento da Conta. O ID agora deverá aparecer como vinculado, mesmo sem conexão com a internet.

### Avisos de Risco
* **Saves Existentes:** Se você mudar o ID de uma conta que já possui saves, esses arquivos podem aparecer como "corrompidos" ou de outro usuário. Use o Apollo Save Tool para resignar os saves se necessário.
* **Não use na PSN:** Este método é apenas para uso offline com Jailbreak.

### Solução de Problemas
* **Payload não carrega:** Limpe os cookies e o cache do navegador do PS4 e tente novamente.
* **Erro de Memória Insuficiente:** Continue tentando; o navegador do PS4 é instável com payloads pesados.
