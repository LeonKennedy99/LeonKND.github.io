Muitas vezes, transferir arquivos PKG gigantes para um HD externo e depois para o PS4 é demorado. O Remote PKG Sender permite que você envie o arquivo diretamente do seu PC para o console através da rede local.

### O que é?
O **Remote PKG Sender** é uma ferramenta para PC que se comunica com o **Remote PKG Installer** do PS4 para realizar a instalação via streaming de dados por rede (HTTP).

### Requisitos
*   **PS4 com Jailbreak (GoldHEN ou similar).**
*   **Remote PKG Installer (RPI):** Homebrew instalado no PS4.
*   **PC e PS4 na mesma rede local:** De preferência ambos conectados via cabo para máxima velocidade.
*   **Arquivos PKG no computador.**

### Passo a Passo
1.  **No PS4:** Abra o aplicativo **Remote PKG Installer**. Verifique o endereço IP do seu console nas configurações de rede.
2.  **No PC:** Abra o programa **Remote PKG Sender**.
3.  **Configuração de IP:** No software do PC, insira o endereço IP que você anotou do PS4 no campo correspondente.
4.  **Servidor de Arquivos:** Clique no botão de configuração e certifique-se de que a interface de rede selecionada no PC seja a correta (a que está ligada à mesma rede do console).
5.  **Adicionar PKGs:** Arraste e solte seus arquivos PKG na lista do programa ou clique em "Add PKG".
6.  **Instalação:** Clique em **Send** ou no botão de play ao lado do arquivo. 
7.  **Monitoramento:** O PS4 receberá o comando e começará a baixar o arquivo como se fosse um download da PSN. Você pode acompanhar o progresso na barra de notificações oficial do PS4.

### Avisos de Risco
*   Instalar via Wi-Fi pode ser instável e causar erros de integridade. Use cabo Ethernet sempre que possível.
*   Não feche o software no PC até que a instalação no PS4 chegue a 100%.

### Solução de Problemas
*   **Erro "Connection Refused":** Verifique se o Remote PKG Installer está aberto no PS4 e se o firewall do Windows não está bloqueando o programa no PC.
*   **Velocidade Baixa:** Certifique-se de que nenhum outro dispositivo está consumindo banda larga intensamente na rede local durante a transferência.
