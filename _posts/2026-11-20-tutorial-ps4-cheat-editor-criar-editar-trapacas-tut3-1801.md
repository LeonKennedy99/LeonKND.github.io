Embora o GoldHEN possua um gerenciador de trapaças nativo, o **PS4 Cheat Editor** é uma ferramenta indispensável para quem deseja personalizar códigos, alterar valores manualmente ou criar novos patches no computador.

### O que é?
É um software para Windows que permite abrir, editar e salvar arquivos de trapaça nos formatos utilizados pelos plugins de cheat do PS4 (como `.json` e `.shn`), facilitando a organização de códigos de vida infinita, dinheiro e modificadores de jogo.

### Requisitos
* **PC com Windows:** .NET Framework 4.5 ou superior instalado.
* **Arquivos de Cheat:** Arquivos baixados do GoldHEN Cheat Manager ou dumpados de jogos.
* **Conexão:** Pendrive ou cliente FTP (como FileZilla) para transferir os arquivos para o PS4.

### Passo a Passo
1. Abra o **PS4 Cheat Editor** no seu computador.
2. Clique em **File > Open** e selecione o arquivo de cheat do jogo que você deseja editar (geralmente nomeado com o CUSA do jogo).
3. Na lista à esquerda, você verá os cheats disponíveis. Clique em um deles para ver os endereços de memória e valores hexadecimais.
4. Para criar uma nova trapaça, clique com o botão direito e selecione **Add New Cheat**. Insira o nome e o código (obtido via ferramentas de busca de memória como o PS4debug).
5. Altere a descrição ou os valores conforme necessário.
6. Clique em **File > Save** para aplicar as mudanças ao arquivo.
7. Transfira o arquivo salvo para o diretório de cheats do seu PS4 (geralmente em `/user/data/GoldHEN/cheats/json/`).

### Avisos de Risco
* Inserir valores hexadecimais incorretos pode causar o travamento imediato do jogo ou corromper o seu arquivo de save.
* Sempre faça backup do arquivo original antes de editá-lo.

### Solução de Problemas
* **O jogo não reconhece o cheat:** Verifique se a versão do jogo (Update) corresponde exatamente ao ID e versão definidos dentro do arquivo editado no PC.
* **Erro ao abrir arquivo:** Certifique-se de que o arquivo não está corrompido e que você está usando a versão mais recente do editor.
