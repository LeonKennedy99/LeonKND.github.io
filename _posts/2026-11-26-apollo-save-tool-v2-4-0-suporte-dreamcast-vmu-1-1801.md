A mais nova atualização do **Apollo Save Tool (v2.4.0)** traz recursos inéditos para a preservação e gerenciamento de saves no PS4. O grande destaque desta versão é o suporte completo para imagens de **Virtual Memory Card (VMU) do Dreamcast**, permitindo listar, importar, exportar e deletar arquivos nos formatos `.BIN`, `.DCM` e `.VMU`. 

Além disso, o desenvolvedor **bucanero** implementou o **Apollo Patch Engine v3.0.0**, que melhora a compatibilidade com scripts complexos e corrige bugs de ordenação de bytes (BSD). Outras adições incluem a renderização correta de ícones 3D de PS2 para VMCs, suporte à decodificação de saves de *MGS Peace Walker* (PSP) e novos prefixos de títulos para organização. Compatível com todos os firmwares com suporte a GoldHEN, a instalação é feita via arquivo PKG através do Package Installer.
