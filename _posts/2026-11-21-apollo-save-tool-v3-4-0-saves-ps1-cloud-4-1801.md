Bucanero lançou o Apollo Save Tool v3.4.0, trazendo funcionalidades muito aguardadas pelos fãs de retrogaming. Agora é possível gerenciar, desbloquear e aplicar cheats em saves de jogos de PlayStation 1 que rodam via emulador nativo no PS4.

### Funcionalidades Adicionadas:
- **PS1 Save Support:** Exportação e importação de arquivos `.mcd` para uso em emuladores de PC ou consoles originais.
- **Dropbox/Google Drive Integration:** Correção no sistema de autenticação para backup automático de saves na nuvem.
- **Editor Hexadecimal:** Melhorias na interface do editor integrado para usuários avançados.

### Uso Sugerido:
Ideal para quem deseja transferir o progresso de um RPG longo do PS1 (como Final Fantasy VII) entre o console e dispositivos mobile ou PC.
