O GoldHEN Cheat Manager foi atualizado para a versão 1.3.0, trazendo melhorias significativas para quem utiliza cheats no PS4. Esta versão foca na otimização do banco de dados, permitindo que a lista de códigos seja carregada instantaneamente, mesmo com milhares de entradas.

### Novidades da v1.3.0:
- **Atualização Automática:** Nova verificação de integridade ao baixar cheats via rede.
- **Interface Aprimorada:** Melhor suporte para visualização de cheats em telas com resoluções customizadas.
- **Compatibilidade:** Funciona em todos os firmwares suportados pelo GoldHEN (do 5.05 ao 11.00).

Para instalar, basta baixar o arquivo .pkg e instalar via 'Package Installer'. Certifique-se de que o GoldHEN está ativo para que o gerenciador possa aplicar os patches na memória do jogo em tempo real.
