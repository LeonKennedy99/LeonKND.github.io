A equipe do GoldHEN lançou o **Virtual Trophy (VTR)**, um plugin inovador que permite aos usuários gerenciar notificações de troféus de forma independente dos servidores da Sony. O plugin é ideal para desenvolvedores de homebrews que desejam adicionar sistemas de conquistas aos seus projetos ou para usuários que preferem um sistema de notificações offline.

O plugin VTR v1.0 integra-se ao menu do GoldHEN e permite que o sistema dispare pop-ups de troféus personalizados durante o gameplay. Ele é compatível com todas as versões de firmware suportadas pelo GoldHEN (do 5.05 ao 11.00).

### Instalação:
1. Certifique-se de estar usando a versão mais recente do GoldHEN.
2. Copie o arquivo `.prx` do plugin para a pasta `/data/GoldHEN/plugins/` no HD interno do PS4.
3. Edite o arquivo `plugins.ini` para incluir o caminho do plugin VTR.
4. Reinicie o console ou recarregue os plugins pelo menu GoldHEN para ativar as funcionalidades.
