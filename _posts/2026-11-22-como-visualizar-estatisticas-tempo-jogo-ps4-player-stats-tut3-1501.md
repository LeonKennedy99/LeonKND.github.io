Diferente de consoles mais recentes, o PS4 não exibe nativamente o tempo total de jogo de forma detalhada para todos os títulos. O **PS4 Player Stats** resolve isso lendo os registros do sistema e apresentando uma interface limpa com suas estatísticas.

### Requisitos
* PlayStation 4 com suporte a instalação de arquivos PKG (Jailbreak).
* Firmware compatível.

### Passo a Passo
1. **Download e Instalação:** Baixe o PKG do PS4 Player Stats e instale-o via *Package Installer* nas configurações de Debug.
2. **Primeira Execução:** Abra o aplicativo no menu principal.
3. **Leitura de Dados:** O app fará uma varredura no banco de dados do console para coletar informações de tempo de execução de cada ID de jogo instalado.
4. **Navegação:** Utilize o direcional para navegar pela lista de jogos. O app exibirá o tempo total jogado, a última vez que o jogo foi aberto e o número de vezes que foi iniciado.
5. **Sincronização:** Você pode atualizar a lista a qualquer momento pressionando o botão de atualização dentro do homebrew.

### Avisos de Risco
* **Precisão:** O tempo de jogo é baseado nos registros internos do sistema. Se o console foi formatado ou o banco de dados reconstruído recentemente, as estatísticas anteriores podem não aparecer.
* **Uso Geral:** O aplicativo apenas lê dados; ele não modifica os arquivos de jogo.

### Solução de Problemas
* **App fechando sozinho:** Certifique-se de que o exploit está ativo. Se o erro persistir, tente desinstalar e instalar a versão mais recente do PKG.
* **Jogo ausente na lista:** O jogo precisa ter sido iniciado pelo menos uma vez no perfil atual para que os dados sejam gerados.
