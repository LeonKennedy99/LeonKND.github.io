O desenvolvedor porttaco liberou a versão **v1.03 do Stremio (Unofficial)** para PS4. Este aplicativo homebrew permite que usuários acessem seus catálogos de filmes e séries favoritos com uma interface adaptada para o controle DualShock 4.

### Funcionalidades:
- Integração com contas Stremio existentes.
- Suporte para complementos (add-ons) de vídeo e metadados.
- Correções de estabilidade na reprodução de vídeo em 1080p.
- Interface mais rápida em comparação com a versão anterior.

**Aviso:** Este é um software homebrew não oficial e requer GoldHEN para funcionar corretamente, pois utiliza recursos nativos do sistema para decodificação de hardware.
