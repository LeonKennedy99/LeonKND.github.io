O aclamado **Boss Rush Mod** de Bloodborne foi finalmente portado e otimizado para consoles PS4 desbloqueados. Este mod altera as Lápides do Sonho do Caçador para permitir que o jogador se teletransporte diretamente para qualquer arena de chefe do jogo, incluindo os chefes das Masmorras Cálice (Chalice Dungeons) e da DLC The Old Hunters.

O mod funciona através da substituição de scripts de mapas e requer que o jogo esteja na versão 1.09. A instalação deve ser feita via pastas de patch ou utilizando o plugin 'GoldHEN Cheat Manager' para carregar os scripts modificados. O mod é compatível com o patch de 60 FPS, proporcionando a experiência de combate definitiva para o título da FromSoftware.
