O desenvolvedor plastikman lançou o **orbis-win v0.0.8**, uma ferramenta experimental que atua como uma camada de emulação/compatibilidade para o PlayStation 4. Esta versão traz otimizações significativas na execução de executáveis simples, focando na estabilidade do sistema ao lidar com chamadas de API traduzidas.

### Características e Uso
O orbis-win permite explorar a execução de aplicações de outras plataformas dentro do ambiente Orbis OS do PS4. Para utilizar o homebrew, é necessário um console com **GoldHEN** ativo. A instalação é feita via arquivo PKG padrão através do Package Installer no menu de Debug Settings. Esta versão v0.0.8 resolve bugs de renderização inicial e melhora a integração com o sistema de arquivos do console.
